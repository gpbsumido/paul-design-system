<Section id="key-changes" title="Key changes">

**The gallery is the regression net.** One story, every form, so a palette or
geometry change shows up in a single Chromatic diff — and the per-chart stories
say which one moved:

```tsx
<div style={{ display: 'grid', gridTemplateColumns: 'repeat(auto-fit, minmax(15rem, 1fr))' }}>
  {/* Sparkline · BarChart · DonutChart · Funnel · Radar · Scatter ·
      Heatmap · Pareto · Gauge · WordCloud · StackedLine */}
</div>
```

It is also the first rendered look at the dark palette. PR B validated those
steps numerically; nothing had looked at them.

**Two stories were teaching the wrong thing.** `DonutChart` pinned its slices to
literal hexes, so it bypassed the palette entirely and, after the recolour,
showed the old colours beside components using the new ones. `BarChart` went
further:

```diff
-export const CustomColors: Story = {
-  args: { colors: ['#22c55e', '#22c55e', '#f59e0b', '#ef4444', '#ef4444'] },
-};
+export const PerEntityColors: Story = {
+  args: {
+    data: [3800, 2600, 1900, 1200, 700],
+    labels: ['NA', 'EU', 'APAC', 'LATAM', 'MEA'],
+    colors: ['var(--paul-chart-1)', /* … */],
+  },
+};
```

Green-to-red by size on one series double-encodes the value as hue and reads as
a status signal the data doesn't carry. The replacement shows what per-bar colour
is actually for.

**The palette page carries the reasoning, not just the swatches** — slot order as
a contract, the ΔE numbers, what to do past six series, and why a green series
does not mean "good".
