# Framework-agnostic charts + React→Angular parity — recap

**Shipped** — the design system now ships `Sparkline`, `BarChart`, and
`DonutChart` in both React (`@paul-portfolio/react`) and Angular
(`@paul-portfolio/angular`), drawn as pure SVG from one shared, unit-tested
geometry core with no charting runtime dependency. Four existing React
components (`Divider`, `Spinner`, `IconButton`, `Switch`) gained Angular twins,
and the Angular package got its first `vitest` config + geometry tests.

<Section id="key-changes" title="Key changes">

**Geometry is the single source of truth (mirrored in both packages).**

```ts
export function donutSegments(values: number[], opts: DonutOptions): DonutSegment[] {
  const total = values.reduce((sum, v) => sum + Math.max(0, v), 0);
  if (values.length === 0 || total <= 0) return [];   // no NaN for empty/all-zero
  // ... walks the circle, one contiguous arc per value, percents sum to 100
}
```

**Charts summarise their data as the accessible name — colour is never the only signal.**

```tsx
const name = data.length > 0 ? `${label}: ${summarise(data, labels)}` : label;
// <div role="img" aria-label={name} className="paul-chart paul-chart--bar">
```

**Token-driven palette a consumer can re-skin from an ancestor.**

```css
.paul-chart {
  --paul-chart-1: var(--paul-color-primary-500);
  /* ...through --paul-chart-6; bars/slices default to fill: var(--paul-chart-N) */
}
```
