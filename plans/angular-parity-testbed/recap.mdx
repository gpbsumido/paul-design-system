<Section id="key-changes" title="Key changes">

**The bug, in one line of output.** Before the build fix, a JIT-compiled
component reported no inputs at all — which is why `setInput` did nothing:

```js
// (X as any).ɵcmp, esbuild + JIT           // after ng-packagr, in dist/types
{ hasDef: true, inputs: {} }                "label": { "alias": "label", "required": false, "isSignal": true }
```

**The build.**

```diff
-  "main": "./dist/index.js",
-  "module": "./dist/index.js",
-  "types": "./dist/index.d.ts",
-  "exports": { ".": { "import": "./dist/index.js", "types": "./dist/index.d.ts" } },
-  "files": ["dist/"],
   "peerDependencies": {
-    "@angular/core": ">=19.0.0"
+    "@angular/core": ">=21.0.0"
   },
   "scripts": {
-    "build": "npx tsc",
+    "build": "ng-packagr -p ng-package.json -c tsconfig.lib.json",
```

ng-packagr writes the entry fields into `dist/package.json` itself, so they come
out of the source manifest and publishing follows:

```diff
-              cd packages/$pkg
+              # ng-packagr writes the publishable manifest into dist/, so the
+              # Angular package is published from there, not from its source dir.
+              if [ "$pkg" = "angular" ]; then cd packages/angular/dist; else cd packages/$pkg; fi
```

Partial mode is not the default here and full mode is unpublishable — ng-packagr
injects a `prepublishOnly` that hard-fails — so `tsconfig.lib.json` states it:

```json
"angularCompilerOptions": { "compilationMode": "partial" }
```

**Two test projects, not one environment.** The geometry suite must not quietly
grow a DOM:

```ts
projects: [
  { test: { name: 'geometry', environment: 'node',  include: ['src/__tests__/**/*.test.ts'] } },
  { plugins: [angular()],
    test: { name: 'render', environment: 'jsdom', setupFiles: ['./test-setup.ts'],
            include: ['src/__tests__/**/*.spec.ts'] } },
]
```

**The Ticker's content difference.** React duplicates `children`; Angular can't
place projected content twice, so the loop renders a template twice:

```html
<div class="ticker__track">
  <div class="ticker__group"><ng-container [ngTemplateOutlet]="body()" /></div>
  <div #clone aria-hidden="true" class="ticker__group">
    <ng-container [ngTemplateOutlet]="body()" />
  </div>
</div>
```

The clone stays clickable but never tabbable — same trick as React, run from
`afterNextRender`:

```ts
private dropCloneFromTabOrder(): void {
  const focusables = this.clone()?.nativeElement.querySelectorAll<HTMLElement>(
    'a[href], button, input, select, textarea, [tabindex]',
  );
  focusables?.forEach((el) => { el.tabIndex = -1; });
}
```

**The character count.** React branches on controlled vs uncontrolled; the
Angular twin seeds from the `value` input and lets typing win:

```ts
private readonly typed = signal<string | null>(null);
readonly count = computed(() => (this.typed() ?? this.value()).length);
```
